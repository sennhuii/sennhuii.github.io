      森辉音乐

      作者：错误符号1002

      功能说明

      • 本地音频播放（mp3 / flac / wav / m4a / ogg）
      • 自动读取音频内嵌封面，无封面则不显示
      • 播放 / 暂停、上一首、下一首
      • 播放队列、列表循环 / 单曲循环 / 随机
      • 倍速播放 0.5x ~ 2.0x
      • LRC 歌词导入与高亮跟随
      • 底部迷你播放条
      • 通知栏媒体控制 + 蓝牙/耳机键
      • 视频播放（自动横屏全屏）
      • 进度条拖拽
      • 本地保存播放进度、倍速、播放模式

      使用方法

      1. 打开页面 → 点右上「+」或发现页「选择文件」添加音频
      2. 也可直接把音频拖进发现页
      3. 点列表里的歌开始播放
      4. 播放页可拖进度、切上下首、调倍速
      5. 点「导入歌词」选同名的 .lrc 文件
      6. 视频点「添加视频」按钮，自动全屏横屏
      7. 关掉网页再打开，进度和设置还在（需重新选文件）
